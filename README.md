# הכפר של החברים — משחק הערכה חינוכי לגילאי גן חובה (5–6)

אפליקציית Web / PWA בעברית מלאה (RTL) המותאמת למסכי מגע (טאבלטים), המאפשרת לילד/ה לשחק בכפר מאויר בליווי גננת המתעדת תצפיות, הקלטות שמע מקומיות והערכה פדגוגית מובנית.

## פרטיות ושמירת נתונים מקומית
- **ללא שרת (No Backend):** כל המידע — פרופילי הערכה, התקדמות במשימות, תגובות, תמלולים, הערות גננת והקלטות שמע — נשמר מקומית בדפדפן באמצעות **IndexedDB (Dexie.js)**.
- **ללא שליחת מידע לצד שלישי:** האפליקציה אינה שולחת הקלטות שמע או נתוני ילדים לשירותי ענן, AI או שירותי זיהוי דיבור חיצוניים.
- **גיבוי ושחזור:** ניתן לייצא קובץ גיבוי מלא (`.json` הכולל גם את הקלטות השמע) ולייבא אותו מחדש בכל עת.

## מה כלול ב-MVP
1. **מסך פתיחה** עם הדמות המלווה **אורי השועל** וכפתור `"מתחילים לשחק"`.
2. **ניהול פרופילי הערכה** (יצירה, פתיחה מחדש להמשך, תאריך, הערות, ייצוא PDF, גיבוי/שחזור ומחיקה עם אישור).
3. **הכפר של החברים** עם 9 מבנים מאוירים:
   - **בית הסיפורים** (פעיל במלואו)
   - 8 מבנים עתידיים המסומנים **"בקרוב"**, כולל **בית האותיות** (לזיהוי ושיום 22 אותיות הא״ב ו־5 האותיות הסופיות).
4. **בית הסיפורים — 5 קבוצות פעילות (8 משימות):**
   - **פעילות 1:** שיום תמונות (10 פריטים מאוירים: בעלי חיים, חפצים ופעולות).
   - **פעילות 2:** סיפור ברצף — רמה א' (3 תמונות) ורמה ב' (4 תמונות) בגרירת מגע (`@dnd-kit`), הקלטה והערכת 6 קריטריונים.
   - **פעילות 3:** הבנת הנשמע — נגן שמע (הפעל / השהה / הפעלה מחדש) + 5 שאלות הבנה.
   - **פעילות 4:** הבנה מילולית — 4א שאלות הבנה (5), 4ב חידות (5), 4ג אוצר מילים (5).
   - **פעילות 5:** מדרש תמונה — סצנת פארק מפורטת + הקלטה, תמלול והערכת 6 קריטריונים.
5. **ייצוא דוח PDF בעברית (RTL)** המבוסס אך ורק על התצפיות שתועדו.

## תוכן זמני ומגבלות בגרסת ה-MVP
- **הקלטת סיפור בפעילות 3 (הבנת הנשמע):** משולב נגן דמה אופליין (צלילי סיפור מובנים באמצעות Web Audio API) וכן טקסט סיפור להקראה על ידי הגננת. להחלפה בקובץ שמע מוקלט, ניתן להוסיף קובץ תחת `public/audio/` ולעדכן את `audioUrl` ב-[storyHouse.ts](file:///home/antigravity/yanai101/childMap/src/content/storyHouse.ts).
- **תמלול אוטומטי בעברית:** אינו זמין אופליין בגרסה זו; הממשק המודולרי ב-[transcription.ts](file:///home/antigravity/yanai101/childMap/src/services/transcription.ts) מציג הודעה ברורה ומאפשר תמלול ידני מלא לצד האזנה להקלטה.
- **מודולים עתידיים:** שאר 8 מבני הכפר (כולל `בית האותיות`) מוצגים כ־`"בקרוב"`.
